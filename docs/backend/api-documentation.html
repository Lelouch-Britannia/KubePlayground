Health Check

Enhanced health check endpoint for container orchestration and monitoring.

Performs comprehensive health checks across all database connections:

  • API service status (always healthy if responding)
  • SQLite connectivity and query test
  • MongoDB connectivity and ping test

Returns: dict: Health status for each component { "status": "healthy" | "degraded" | "unhealthy", "api": "healthy", "sqlite": "healthy" | "unhealthy", "mongodb": "healthy" | "unhealthy", "timestamp": "2026-02-01T12:00:00Z" }

Status Codes: 200: All systems healthy 503: One or more systems unhealthy (Service Unavailable)

Note: Container orchestrators (Docker, Kubernetes) use this endpoint to determine if the service should receive traffic. Failing health checks trigger container restarts.

Supports course/topic hierarchy via embedded metadata:

  • course: {slug, name} - Auto-creates course if missing
  • topic: {slug, name, order, icon} - Auto-creates topic if missing
